# 🛠️ My DevOps & Linux Deployment Tools

Welcome to my deployment tools repository! This repository contains a collection of utility tools and generators designed to simplify, automate, and speed up the deployment of web applications (such as .NET APIs) on Linux servers, Plesk, and Nginx.

---

## 📂 Available Tools (ابزارهای موجود)

### 1. 🚀 [Smart Linux & Plesk Deployment Generator](./Smart%20Linux%20%26%20Plesk%20Deployment%20Generator/)
An interactive web tool to automatically generate Nginx configurations, Systemd service files, and deployment scripts for hosting .NET applications on Linux/Plesk.
* **Features:** Multi-language (English/Persian/Arabic), free port detection script, automated hot-reload setup.
* **How to use:** Navigate to the folder and open `index.html` in any browser, or use the online link if GitHub Pages is active.

*(More tools will be added here in the future!)*
